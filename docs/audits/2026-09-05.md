## 1. Verdict

The owner's diagnosis is right, and the reasons are specific.

**The GUI falls short on day-one desktop basics that are local, cheap,
and mostly not on the arc's blocker list.** The window opens at
**800×200 logical pixels** (`INITIAL_HEIGHT: 200`,
`pmacs-gpu/src/main.rs:350`) and never remembers its size. HiDPI is
rendered at scale 1.0 (eleven hardcoded `scale: 1.0` sites, no
`ScaleFactorChanged` arm), so text is half-size on a 2× display. There
is **no scrollbar**, **character wrap instead of word wrap**
(`Wrap::Glyph`, `:6539`), a static title, no cursor blink, a hardwired
palette, and on macOS **Cmd-C/V/X/Z/S/A do nothing** because Super is
withheld and winit installs no Edit menu. A daemon crash leaves a
half-dead window with no reconnect. `C-x 2` splits invisibly and `C-x o`
teleports the caret to byte 0. Of these, only splits and reconnect are
structural. The rest are one-file, S-to-M changes, and the arc's stage
map defers two of the cheapest (scrollbar to Stage 7, word wrap behind a
UAX #14 grid-parity condition) on premises the code does not support:
the GPU already holds the full text and viewport locally, and
cosmic-text already implements word wrap one enum value away.

**The TUI is "ok" rather than excellent because of a cluster of
keyboard-loop absences any Emacs or Helix user hits in the first
minute.** `C-x C-c` **exits with unsaved buffers and no prompt**
(`editor.quit` sets the flag, `src/lua_bindings/mod.rs:13828`; nothing
checks modified state). `C-g` sets the status to "Quit" and does not
clear the selection. There is no `C-SPC` mark, no `M-<`/`M->` outside
terminal copy mode, no `C-l`, no `C-u`, no `C-x k`, no `C-x C-w`. TAB
inserts a literal tab in every language. Line numbers default off and
the toggle is M-x-only. Undo is one entry per keystroke with no
amalgamation. The minibuffer shows one candidate on one row and a
selected candidate shadows typed text, so `C-x C-f nots RET` opens
`notes.md`. `find-file` completes within one directory; there is no
project-wide file finder although every ingredient (a cancellable tree
walk, a custom completion source, fuzzy scoring) exists and is tested.
The first cluster is under a hundred lines of Lua over primitives that
already exist.

**Coherence fell short for the reason `COHERENCE.md` §1.1 named in
July, and the pattern has not reversed since.** Substrate without
surface: `pmacs.error` is still undefined in production with **18**
guarded dead call sites (up from 15) while Rust carries **seven**
copy-pasted `*errors*` writers, five of which never reach the status
line; `pmacs.hook.remove` still does not exist; **~39 commands are
unbound including the entire `help.*` family**, zoom, git status, LSP
status and the workers view; `*buffer-list*` is a plain writable buffer
a user can type into; a language server that crashes is consumed
silently; workspace-symbol search has a request, a store, and no
command; `FoldState` is produced and never consumed;
`HoverView`/`SignatureView` are built and never attached; rust-analyzer
semantic tokens refine highlighting in the TUI and not in the GPU
because the two paths implement opposite merge policies.

**The structural ceiling has a clear answer and a false gate.** The
daemon already owns per-frontend window trees for both frontends; the
GUI's one-window model is a projection gap, not a model gap. The right
Stage 6 shape is to project the window *tree* (weights plus opaque
window keys plus per-window facts) and let the frontend compute
geometry — the bottom panel already works exactly this way. Session
restore on the GUI does not need the P2 workspace object: the daemon
holds the layout, the per-window state, and a serializer; what it lacks
is a session identity that survives a socket. That identity is also the
prerequisite for reconnect, so it is the first structural PR.

**The process is now consuming the capacity that would produce
coherence.** The three required-reading documents (10,238 lines)
disagree with each other and with the code on the five facts an agent
loads first: protocol version (four values; code is v25), canonical base
(two values in one file), GUI arc state (three places say Stage 1a is
not started), settings adoption (5 / 9 / actual 15), and open blockers
(9 / actual 6). Forty-five percent of commits since July are docs
commits; over the last forty merges docs and source changed lines are
1.01:1; 91% of the "volatile" ledger is resolved history. #247 took 20
days and 72 commits, the first week on framing revisions 13 through 22;
#241 was an entire lane (2,182 doc lines, 0 source lines) on a bug that
did not exist. Ten of the 31 CI-red registry rows are wall-clock budgets
asserted in debug builds on a shared machine; every one was green in
isolation and none was diagnosed. In the last twenty days, three merges
changed something a user can see.

None of this is a verdict on the engineering, which is careful and often
excellent. It is a verdict on allocation. **The editor is a few dozen
small, local changes away from feeling like a real editor on both
frontends, and the current process schedules those changes behind
wire-bearing stages and evidence work.**

## 2. Direction

### 2.1 Principles for the next quarter

1. **Doors before engines.** Every week ships at least one change a
   user can see, on a frontend they use. No more than two consecutive
   infra/test/docs PRs.
2. **Local before wire.** Anything achievable frontend-locally ships
   before its protocol-bearing generalization. The wire is an asset to
   protect, not a toll to pay per feature.
3. **Declared divergence is honesty, not debt.** #221's ruling on word
   wrap (GUI-first, declared in `gui-arc-framing.md` §3.2) is the model.
   Use it for the scrollbar, word wrap, cursor blink, and hover.
4. **The framing scales with the change.** A one-file, local, S change
   gets a paragraph and a PR, not a numbered-decision document. Framings
   cap at five revisions or one closure audit, then split or
   approve-with-open-questions.
5. **Evidence that measures the machine, not the tree, is not a gate.**
   Wall-clock budgets in debug builds move behind `#[ignore]` into the
   perf jobs that already exist.

### 3.2 Findings

- **F1 · High · 800×200 initial window, no geometry persistence.**
  `INITIAL_WIDTH/HEIGHT` `:349-350`; `with_inner_size(LogicalSize)`
  `:6339`. S.
- **F2 · Critical on HiDPI · scale 1.0 everywhere.** `ScaleFactorChanged`
  arm plus one `scale` field through `TextArea`, quads, squiggles, hit
  tests and `FrontendCellGeometry`; the Stage 1 framing's rows C5a/C5b
  already enumerate it. M.
- **F3 · High · no scrollbar.** The minimap thumb appears only when a
  `FileStyleSummary` exists. Every fact (`scroll_top`,
  `current_line_starts.len()`, `view_range` `:1797`) is local. The arc's
  Stage 7 premise ("needs authoritative extent") holds for horizontal
  scroll, not vertical. S.
- **F4 · High · character wrap.** `Wrap::Glyph` `:6539`/`:11293`; the
  file's own comment says cosmic-text's constructor default is
  `WordOrGlyph`. Q#GA9 ties the value to a UAX #14 grid implementation.
  Ship GPU-first with a §3.2 entry. S.
- **F5 · High · daemon splits invisible but not inert.** The producer
  follows `primary_document_window` (`src/editor_core.rs:3177`); a new
  window's cursor is 0; `C-x o` teleports. Interim: refuse or echo on
  semantic frontends (S); real fix is §6.1 (L).
- **F6 · High · daemon death.** Status band, minimap and summary stay
  painted over "(daemon disconnected)"; later keys go to stderr
  (`:3916`); reader/writer join handles are dropped
  (`pmacs-gpu/src/attach.rs:680,720`), so an in-flight `CrdtOp` at close
  is unflushed. M with §6's identity.
- **F7 · Medium · panics on missing adapter/surface/device**
  (`:6344-6363`); the headless path already handles absence with
  `.ok()?`. The spawned daemon's stderr is `/dev/null`, so daemon-side
  attach failures are undiagnosable from `--gpu`. S.
- **F8 · Medium · `pmacs --gpu` refused on a default build.**
  `src/main.rs:325-328` gates on `cfg!(feature = "crdt")`; `crdt` is
  not default. The dependency is on text transport (`semantic_render ⇒
  crdt_replica`, `pmacs-protocol/src/message.rs:2612-2624`), not on
  semantics. S, or a decision (§12).
- **F9 · High on macOS · Cmd shortcuts dead.** `translate_mods` maps
  Super → META `:14034`; `should_forward_key` `:14244` withholds META
  chords; winit 0.30's macOS menu installs Services/Hide/Quit only, so
  Cmd-C/V/X/Z/S/A have no responder. S island / M via Stage 2.
- **F10 · Medium · no GUI-only bindings; Ctrl+wheel ignored; zoom
  unbound.** `keymap_stack::Scope` has no frontend identity;
  `apply_wheel` computes `mods` `:3568` and ignores them;
  `gpu.zoom-*` exist with no `keymap.bind`. M (Stage 2).
- **F11 · Medium · fixed 2px caret, fixed color, no blink, no focus
  dimming.** S.
- **F12 · Medium · own current-line highlight dropped `:12631`; no
  paren match, indent guides, whitespace rendering, OS light/dark.** S/M.
- **F13 · High for LSP users · hover and signature are one status
  line.** `HoverView`/`SignatureView` are never constructed;
  `lsp.hover_at_cursor` echoes the first line. M (Stage 5).
- **F14 · Medium · per-frame chrome reshaping.** Gutter, menu,
  minibuffer and completion buffers `refresh_*` every frame even when
  closed; eight `prepare` calls; nearly every wire message ends in
  `request_redraw`. S–M dirty flags.
- **F15 · Medium · large files.** Per-keystroke work is slice-scoped
  (`rebuild_code_slice` `:11202`, fine); `set_text` `:7095` rebuilds all
  line tables on snapshot/switch; `widest_display_columns` scans for the
  horizontal clamp. M.
- **F16 · Medium · fixed-advance assumptions** for horizontal scroll and
  gutter width; no emoji/color fonts. M.
- **F17 · Medium · serial startup.** No window until the snapshot lands;
  `read_initial_target_bootstrap` has no timeout; fonts load on the main
  thread. M.

### 4.2 Findings

- **Minibuffer (High).** `recompute_candidates` selects index 0 whenever
  the list is non-empty (`src/minibuffer.rs:371-378`);
  `resolve_accepted_value` prefers the candidate (`:564-574`); pinned as
  a decision in `tests/find_file_acceptance.rs:306-330`. `TAB` replaces
  the input with the selection (`:260-268`). One candidate painted
  inline (`paint_minibuffer` `editor.rs:6774-6800`). Files completion is
  single-directory, unsorted, 1024-capped; custom sources are truncated
  to 1024 **before** filtering (`:590-599`) and `filter_and_sort` takes
  before it sorts (`:672-680`), so any large Lua-built picker ranks
  wrong. On empty input `find-file` opens the lexicographically first
  candidate (`default.lua:640-656`). Rating 3/10 as a picker.
- **Undo (Medium).** No amalgamation, no cap. Key it off the
  `rotate_command` boundary already stamped at `editor.rs:1965/1978`.
- **Line index rebuilt to EOF per edit per window (Medium perf).**
  `TextView::on_edit` → `rebuild_lines_from` (`src/text_view.rs:109-131`).
  Shift the tail by the newline delta instead.
- **Whole-buffer copies per frame (Medium perf, latent High).**
  `SearchView::render` while matches exist — and they persist after
  `RET` until the next edit (`src/search.rs:414-440`);
  `DiagnosticView::render` (`src/diag.rs:523-550`);
  `LspStyleView::render` (`src/highlight.rs:642-690`); isearch copies
  the buffer per keystroke (`editor_core.rs:1554-1562`). No
  non-`#[ignore]` gate bounds any of this; the 100 MB gates are
  rope-only.
- **Unicode (Medium).** Motion is codepoint-, not grapheme-based
  (`editor_core.rs:2207-2240`); CR is an invisible zero-width cursor
  stop on CRLF files; go-to-definition walks the cursor one line at a
  time (`lsp.lua:1593-1602`, `compile.lua:944`) while `move_to_line`
  exists.
- **`kill_buffer` refusal is destructive (Medium).** Windows are
  redirected and round-trip state cleared before `registry.remove` can
  return `ConcurrentEdit` (`editor_core.rs:5375-5427`).
- **Shadow ladder (design).** Four full shadows plus the partial popup
  and the terminal transport; now **four** hand-synced guard lists
  (`dispatch_text_input`'s `feed_shadow_scalars` joined the three).
  `describe-key` is unaware of any of them. The transient layer is L; the
  minibuffer rung can land alone and is the one that also adds user
  value (`C-k`, `M-BS`, `C-y` in prompts).
- **Discoverability.** The only prefix feedback is `[C-x-]` in the
  status line; no which-key; `F1` is free.
- **Attached TUI.** `crdt` is not a default feature, so a stock build
  round-trips every keystroke over SSH; optimistic paint flashes
  unstyled for a frame.

## 6. Protocol, daemon, multi-frontend

- **Wire at HEAD**: v25, advertised 20, supported 6..=25.
  Defined-never-produced: `ModeLine`, `Signal::Title`,
  `BlockAdornments`, `ResourceOffer`. Produced-never-consumed by the only
  semantic consumer: `FoldState`, `Signal::Bell`, the live `Goodbye`
  reason, `CompletionPopup.prefix_len/total`. Shipped and discarded:
  `PresenceUpdate` to grid peers; N−1 attach `BufferSnapshot`s (the GPU
  keeps the last). The GPU never sends `FocusGained/Lost` or `Detach`.
- **Session identity does not survive the socket (High).**
  `FrontendId` is per-connection; on EOF the `FrontendView` is dropped
  (`src/daemon.rs:3017`, `editor_core.rs:1022`; windows leak — the
  "M10.x may add pruning" comment at `editor_core.rs:1017-1021` never
  did) and the next attach clones LOCAL (`daemon.rs:3870`). Reconnect as
  framed would return to the wrong buffer with no layout. Fix: session
  token in `Hello`, appended `FrontendEvent::Resume`, view retention. M.
- **`C-x C-c` from any frontend kills every frontend (High).**
  `core.quit` → `Goodbye(ShuttingDown)` to all streams
  (`daemon.rs:1951-1961`). Non-LOCAL quit should detach. S.
- **No daemon lifecycle (Medium-High).** No `--stop`/`--status`/`--list`,
  no idle exit, stale sockets unlinked only at the next start, a wedged
  daemon holds the flock, and the documented recovery is `pgrep`/`kill`.
  S–M.
- **`Viewport` mutates window state** (`align_primary_document_window`
  `daemon.rs:3817-3856` resets the cursor to 0). Any per-window model
  breaks on it. Part of Stage 6.
- **Oversize `BufferSnapshot` silently skipped** (`daemon.rs:3120-3125`);
  a >16 MiB loro snapshot leaves the GPU at "(connecting...)". S–M.
- **Attach is O(all buffers); every switch reships a full snapshot and
  resets 12 baselines** (`src/semantic_render.rs:1120-1140`). M.
- **Per-tick costs to fix before per-window multiplies them**:
  statusline Lua providers evaluated every frame per semantic peer
  (`semantic_render.rs:1200-1210`); the minimap summary is a whole-file
  tree-sitter query per keystroke (`:3502-3560`).
- **The write gate is fourteen hand-written `peer_knows_*` conditionals**
  (`daemon.rs:1716-1855`); a table-driven `min_version` in the protocol
  crate would replace them. Seven literal version tripwires are
  scattered across tests.
- **Structural cliff**: any change to a shared struct (`Style`, `Cell`,
  `CellSize`, `Key`, `Modifiers`) is a v6-class break the ladder cannot
  absorb. Freeze them; route new facts through appended variants.
- **The attached TUI is a grid client** (`src/attach.rs:592`), so every
  semantic feature has one consumer and exists twice. Cheapest
  guarantee: every semantic variant gets an arm in the headless
  `SemanticClient` with a reconstruction-equivalence test, so
  produced-never-consumed becomes a failing test rather than a doc row.

### 6.1 Stage 6: Model A

Project the per-frontend window **tree**, not rectangles:
`WindowTree { root: Leaf(WindowKey) | Split { orientation, weights,
children }, active, generation }` with an opaque monotonic `WindowKey`
(the `panel_epoch` discipline); `WindowFacts { window, buffer_id,
cursor, selection, line_numbers, view_top_hint, focused }` for the facts
that are per-buffer today by accident (`CursorByte`, `LineNumbers`,
`Decorations::Selection`); a per-window statusline twin;
`FrontendEvent::WindowViewport` that **does not align**;
`WindowPointer`; `Subscribe`/`Unsubscribe` replacing snapshot-everything
and follow-the-active-buffer. `Layout::compute` moves beside
`scroll::classify`. Keys still target the daemon's `active` window, so
`C-x o` stays shared. Reasons: the daemon already owns windows for both
frontends (`FrontendView.layout` is per-`FrontendId`, `src/window.rs:653`);
`C-x 2` already splits the GPU's view invisibly; the panel is the
working precedent; a projected tree is what restore serializes. Model B
either forks window semantics into the GPU or mirrors the tree anyway.

### 6.2 Restore does not need P2

`src/desktop.rs:339,369` early-return on `DaemonMode`; `snapshot()`
reads only `core.views[LOCAL]` (`:266`). The daemon has every fact a v1
needs. Owner = daemon; timing = detach, shutdown, explicit command;
arbitration = one snapshot per `(daemon key, frontend kind)`,
last-detached-wins, declared in §3.2. P2 later re-keys a string. Gating
this on P2 keeps the GUI at "restore: never" for the life of the
workspace arc in exchange for nothing a two-line key change would not
also give.

## 12. Decisions only the owner can make

1. **Order.** Accept §2.2's program, or keep the arc's stage order
   (1c → 1d → 1e → 2 → 3 → 4 → 5 → 6)? The stage order optimizes wire
   discipline; the program optimizes the daily-driver gap. They diverge
   at 1d/1e/2, which the program moves behind slices 8–10.
2. **Restore v1 without P2.** Q#GA5 gates Stage 4b on starting P2. §6.2
   says a daemon-keyed snapshot is honest and re-keys later. Overrule
   Q#GA5, or keep it?
3. **`crdt` as a default feature.** The default build produces a `pmacs`
   that refuses `--gpu` and an attached TUI that round-trips every key.
   Is the non-CRDT build a product line or a build option nobody uses?
4. **The minibuffer accept pin.** `tests/find_file_acceptance.rs:306`
   pins "a new name that is a subsequence of an existing entry opens the
   existing file" as a decision. Is it one?
5. **Budgets.** Move the seventeen wall-clock assertions behind
   `#[ignore]`, accepting that a debug-only perf regression is caught by
   the release perf jobs rather than every gate run?
6. **Framing cap and cadence rule.** Five revisions or one closure
   audit; one user-visible merge per week. These change how the owner
   reviews, not only how agents work.
7. **`Command.predicate`.** Retire the field (cheapest; removes a false
   affordance) or wire it into invoke and M-x filtering?
8. **Styling authority.** Should the GUI adopt the grid's merge of
   tree-sitter and LSP tokens, or the grid adopt Policy A? Today they
   contradict and the GPU user sees the difference.
9. **The `pmacs` dev-dependency of `pmacs-gpu`** (#247): a one-off
   witness or a direction? If a direction, a shared-frontend crate is
   where the substrate belongs.
10. **Zoom and Cmd bindings now or after Stage 2?** A declared island
    is cheap and removable; the handoff currently says hold.
